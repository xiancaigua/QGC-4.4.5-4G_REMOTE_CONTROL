## 测试边界

本机未发现 PX4 SITL、PX4 可执行文件或已安装的 WSL 发行版。本地回环端点只提供心跳与接收报文，不是飞行模拟器，也不回应完整参数协议。没有连接真实飞机或执行飞行测试。两轮人工操作已验证八个键位的 MAVLink 轴值、油门连续增减与松开保持、D+↑ 组合输出及方向轴松开回中。键盘自动重复的原始事件状态、相反键是否同时按下无法从 MAVLink 报文直接观察，故只确认了对应时段的净轴值。滑条只验证了显示值变化，尚未验证改变后对控制轴的实际影响。实体手柄冲突、触屏虚拟摇杆冲突、飞机切换的运行时行为也未做联机实测。面板位置约束修正后的拖动和展开收起已复测，先前暂时不可见的问题仍需复现定位。

4.4.4 仅完成独立工作树的源码接口检查，未编译或启动。安装包未生成和测试，因为本机没有 NSIS，且官方安装器配置使用固定 C 盘路径。
